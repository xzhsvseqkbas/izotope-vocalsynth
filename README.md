## Overview

iZotope VocalSynth 2 combines vocoder, talkbox, biovox, polyvox, and compuvox synthesis engines to transform vocal recordings into synthetic, robotic, or harmonically rich vocal effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iZotope VocalSynth** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Five Engines** | Vocoder, talkbox, biovox, polyvox, and compuvox in one plugin |
| **Harmony** | Real-time harmony from MIDI or scale-based chord detection |
| **Choir Mode** | Multiple voice stacking for choir and ensemble vocal effects |
| **Formant Control** | Independent formant shifting per synthesis engine |
